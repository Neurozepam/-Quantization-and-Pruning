## D05 — начало sprint после учебных D01–D04

### Согласованные решения

- D05 означает первый день research sprint, не пятый день календаря sprint.
- Задача: activation clipping, продолжение локального эксперимента D04.
- План: экспериментальная схема → роли данных → контроль ресурсов → scope → timing → бюджет.

### Диагностика и закрепление

- Первоначальная путаница: output MSE при замене X была названа квантованием весов. Последующие проверки различия X_hat/W_hat и задачи пройдены.
- Численная связь ошибки входа с весами понятна; запись e^T W^T W e пока не знакома. Для сегодняшнего эксперимента достаточно прямой оценки выходов; матричный вывод не использован как обязательная основа.
- Calibration и development сначала смешивались; проверка зависимости метода от просмотренного test пройдена после разбора.
- Контроль сетки порогов сначала не выделялся; проверки одного изменяемого компонента и одинакового общего token budget затем пройдены.
- Синхронизация CUDA и расчёт бюджета поисков проверены quiz.

- Установлена datasets 5.0.1 с ограничениями на рабочие torch/transformers/tokenizers/hub/numpy. Fsspec изменён с 2026.7.0 на 2026.6.0; pip check прошёл. Версии сохранены в configs/environment_freeze.txt.
- audit_wikitext.py загрузил только train и validation по закреплённой revision. Отчёт results/wikitext_audit.json. Общие непустые stripped-строки: 147; 146 начинаются с '=', одна — 'Source :'. Это не доказательство совпадения статей.
- Пользователь самостоятельно реализовал sample_blocks в src/prepare_wikitext.py. Тесты выбора разных статей, одинакового seed, точного среза, неизменности pool и крайнего случая N=L прошли.
- Первый полный запуск завершился AssertionError: каркас ошибочно требовал 64 статьи в validation. Проверка обнаружила 60 статей, все длиной >=128 токенов. Исправление: до 64 статей с фиксацией actual_pool_sizes, не изменение пользовательской функции.
- Предупреждение tokenizer о длине полной статьи >8192 не означает запуск длинной последовательности в модели: на этом этапе только encode, модель позже получит отдельные блоки по 128 токенов.
- Повторный запуск успешен: data/wikitext_blocks.json. Train pool=64, validation pool=60; 8 calibration subsets по 256 токенов, общий development=2048 токенов. Выборки могут пересекаться; независимость повторов не заявляется.
- Совпадения точных статей между пулами и совпадения целых выбранных token blocks между calibration/development отсутствуют по проверкам. Это не доказывает отсутствие частичного совпадения текста или pretraining overlap.
