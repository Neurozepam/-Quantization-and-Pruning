# DAY 2 — промежуточный результат: гранулярность

## Метод
- NumPy, seed 42; матрица 64 × 256: стандартная нормальная выборка, строки умножены на `np.geomspace(0.1, 10.0, 64)`.
- Симметричный INT4: коды от -7 до 7, scale = max(abs(group)) / 7.
- Одна и та же матрица для всех сравнений; группы внутри строк, без padding.
- Per-output-channel = per-row при соглашении W[out, in]. Per-row здесь эквивалентен g256.
- MSE измерена с float64 scales. Размер ниже — расчёт для packed INT4 + FP16 scales, не измерение фактической памяти NumPy. Влияние округления scales в FP16 не проверено.

## Результаты
| Метод | MSE | Scales | Overhead относительно кодов | Бит/вес |
|---|---:|---:|---:|---:|
| Per-tensor | 0.924991 | 1 | 0.024414% | 4.0009765625 |
| Per-row (g256) | 0.170084 | 64 | 1.5625% | 4.0625 |
| g128 | 0.147453 | 128 | 3.125% | 4.125 |
| g64 | 0.128378 | 256 | 6.25% | 4.25 |
| g32 | 0.104619 | 512 | 12.5% | 4.5 |

Формулы: code_bits = N * 4; scale_bits = n_scales * 16; overhead_pct = 100 * scale_bits / code_bits; bits_per_weight = (code_bits + scale_bits) / N.

## Вывод
На этой синтетической выборке отдельные scales снизили MSE. Более мелкие группы дали меньшую ошибку ценой дополнительных scales. Это не гарантия монотонного улучшения для любых данных и не проверка качества модели.
