# Бейслайны без квантования и прунинга

Для общей таблицы по новым экспериментам используйте повторные прогоны. Они оценивают исходные чекпойнты на тех же выборках и по тем же правилам, что и сжатые варианты в `results`.

| Чекпойнт | Формат | Оценка | Метрика | Параметры | Размер |
|---|---|---|---:|---:|---:|
| LeNet + BatchNorm | FP32 | MNIST test, 10 000 изображений | **98,55% top-1** | 44 470 | 183 530 байт, файл `state_dict` |
| SmolLM-135M | FP16 | WikiText-2 raw test, окно 512, шаг 256 | **18,386945 PPL** | 134 515 008 | 269 030 016 байт, объём тензоров |

У LeNet 9 855 правильных ответов из 10 000 при нормализации MNIST со средним 0,1307 и стандартным отклонением 0,3081. У SmolLM оценены 304 828 предсказываемых токенов. Каждый токен учитывается один раз, пустые строки исключены, текст соединён двумя переводами строки. Оба чекпойнта оценены без дополнительного обучения. Для сравнения задержки используйте замеры из одной сессии в CV-ноутбуке. В повторном прогоне медиана LeNet составила 0,29 мс для batch 1 и 9,45 мс для batch 256.

## Повторный запуск

Из корня репозитория в окружении с PyTorch CUDA, Transformers, PyArrow и Datasets.

```powershell
.venv/Scripts/python.exe baseline/evaluate.py
```

Для LeNet скрипт проверяет SHA-256 сохранённого чекпойнта из `quantization/research/cnn_ptq/artifacts/fp32`. Для SmolLM в коде закреплены ревизии модели и датасета. Скрипт использует кеш предыдущего эксперимента при наличии, иначе загружает SmolLM и WikiText-2. Общий LLM-прогон выполняется на CUDA в FP16.
